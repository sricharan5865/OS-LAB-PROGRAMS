Experiment-Fork() : Command Execution using fork(), exec(), 
and wait() 
 
Aim: To develop a C program that demonstrates how a Linux operating system 
executes a command entered by a user using fork(), exec(), and wait() system calls. 
 
Program 1: One Process (Before fork()) 
 
#include <stdio.h> 
#include <unistd.h> 
int main() 
{ 
    printf("PID = %d\n", getpid()); 
    return 0; 
} 
Only one process exists. 
Introduce getpid(). 
 
Output :   PID = 2456 
 
Program 2: fork() Creates a Child 
 
#include <stdio.h> 
#include <unistd.h> 
int main() 
{ 
    fork(); 
    printf("Hello\n"); 
    return 0; 
} 
How many times will "Hello" print? 

--- PAGE 6 ---
Output 
Hello 
Hello 
 
Concept:  One process becomes two processes. 
 
Program 3: Parent vs Child  
 
#include <stdio.h> 
#include <unistd.h> 
int main() 
{ 
    pid_t pid; 
    pid = fork(); 
    if(pid == 0) 
        printf("I am Child\n"); 
    else 
        printf("I am Parent\n"); 
    return 0; 
} 
 
Output 
I am Parent 
I am Child 
 
Concept 
fork() returns 0 in the child. 
fork() returns child PID in the parent.

Program 4: Display Both PIDs  
 
#include <stdio.h> 
#include <unistd.h> 
int main() 
{ 
    pid_t pid; 
    pid = fork(); 
    if(pid == 0) 
    { 
        printf("Child PID = %d\n", getpid()); 
        printf("Parent PID = %d\n", getppid());

    else

        printf("Parent PID = %d\n", getpid());

Program 5: Parent Waits for Child

Program 7: Child Executes Another Program (exec()) 
 
#include <stdio.h> 
#include <unistd.h> 
int main() 
{ 
    pid_t pid = fork(); 
    if(pid == 0) 
    { 
        printf("Child executing ls...\n"); 
        execl("/bin/ls","ls","-l",NULL); 
    } 
    else 
    { 
        printf("Parent Waiting...\n"); 
    } 
    return 0; 
} 

--- PAGE 10 ---
 
Concept 
exec() replaces the child process with another program. 
 
 
Program 10: fork() Inside a Loop (Fun) 
 
#include <stdio.h> 
#include <unistd.h> 
int main() 
{ 
    int i; 
    for(i=0;i<3;i++) 
        fork(); 
    printf("PID = %d\n",getpid()); 
    return 0; 
} 
 
How many processes are created? 
 
Answer:  2^3 = 8

Explanation: 
1)​fork()- Creates a new child process. 
 
pid_t pid = fork(); 
2)​exec()- Replaces the child process with the command entered by the 
user. 
 
execlp(cmd, cmd, NULL); 
3)​wait()- Makes the parent process wait until the child process finishes. 
 
wait(NULL); 
4)​getpid()- Returns the Process ID of the current process. 
 
5)​getppid()- Returns the Parent Process ID.
