# Skill Activity 08: Process Tree & Hierarchy Analysis

## Aim & Overview
Analyzing multiple fork() calls, process hierarchy trees, PID lineage, and inspecting process trees using pstree / ps.

## Implementation (`main.c`)
```c
// Skill 08: Process Tree Analysis
#include <stdio.h>
#include <unistd.h>

int main() {
    fork();
    fork();
    printf("Process PID: %d, Parent PID: %d\n", getpid(), getppid());
    return 0;
}
```

## Compilation & Execution
```bash
make
./main
```

## Output & Verification
```text
Process PID: 7101, Parent PID: 7100
Process PID: 7102, Parent PID: 7101
Process PID: 7103, Parent PID: 7100
Process PID: 7104, Parent PID: 7103
```

## Key Learning Points
Calculated 2^n = 4 total active processes generated by 2 sequential fork() system calls.
